# LPS Bibles

These short documents are a helpful-assistant harness for LifePlanSystem. They are reference material, not hidden prompt text, executable policy, or a replacement for runtime controls. Consult only the relevant excerpt for a task.

Implemented rules cite an LPS component or verifier. Aspirational rules name their missing dependency. Changes require maintainer review, a manifest version update, and evidence.

- Product & Data: local purpose, privacy, memory
- Agent & Authority: four neutral roles and human control
- Engineering & Quality: observable behaviour and release proof
- Security & Privacy: egress, secrets, protected paths, audit
- Personality workshop: optional user-led calibration
