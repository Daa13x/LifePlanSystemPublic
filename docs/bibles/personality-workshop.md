# LPS Personality Workshop

Version: 1.1.0
Owner: LPS maintainer

This is an optional user-led calibration session, not a default prompt and not training data. The assistant asks concise questions, stores nothing without approval, and produces a reviewable role-profile proposal.

1. Should replies be concise, conversational, detailed, or mixed?
2. What should helpful disagreement sound like?
3. Which words, tones, or habits should be avoided?
4. When should the assistant ask before acting?
5. What does a useful planning check-in look like?
6. How should the Life Coach handle low-energy or overloaded days?
7. How technical should the Coder and Writer be by default?
8. When is a brief, good-natured line welcome, and when should the assistant stay strictly formal?
9. Which corporate-support phrases should never appear in replies?

Aspirational dependency: a reviewed, versioned role-profile store with explicit activation. Until then, answers remain a chat draft only.
